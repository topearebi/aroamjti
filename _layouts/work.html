--- layout: default --- {%- comment -%} Unified work layout. A work is a curated reading order laid over posts. Its `parts:` list is ordered; each entry is one of: - heading: "III" a section label / chapter marker - inline: | literal text transcribed in the work file ... - post: "slug" a pointer to a published post (pulls title + body) Posts are never edited and never know they belong to a work. Membership lives only here, so referencing a post is non-destructive. BACKWARDS COMPATIBLE: a work with no `parts:` simply renders {{ content }} exactly as before (the legacy inline model). Both can coexist indefinitely, and a single work may mix inline parts with post references. {%- endcomment -%}
